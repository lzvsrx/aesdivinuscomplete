# Contatos de Autoridades Ciberneticas, Privacidade e Plataformas

Versao: 2026-08-24

Este documento lista canais oficiais para incidentes ciberneticos, privacidade, abuso online, propriedade intelectual e plataformas usadas pelo projeto Aes Divinus. Contatos governamentais mudam; antes de enviar qualquer comunicacao formal, confirme no site oficial e consulte o responsavel juridico/seguranca da LZASANTOSWORLDSGAMES.

## Regra de uso

- Use este documento como mapa de triagem.
- Preserve evidencias antes de enviar denuncia, remover arquivo ou revogar acesso.
- Nao envie dados pessoais desnecessarios para canais publicos.
- Em risco imediato a vida, crianca/adolescente, extorsao ativa ou crime em andamento, acione a policia/local emergency service primeiro.
- INTERPOL normalmente nao recebe denuncias diretas de individuos/empresas; a comunicacao deve passar pela policia local/nacional quando for preciso coordenacao internacional.

## Gatilhos de comunicacao por tipo de problema

| Problema | Comunicar internamente | Autoridade/plataforma provavel |
| --- | --- | --- |
| Vazamento de email, identificador, save ou token | Juridico, DPO/privacidade, seguranca | ANPD/DPA local, titulares afetados, plataforma afetada |
| Token GitHub exposto | Seguranca, dev lead, dono do repo | GitHub; ANPD/DPA se houve dado pessoal |
| Build adulterada | Seguranca, release manager, juridico | GitHub Releases, Steam/Google/Apple; policia se houver crime |
| Phishing usando a marca | Juridico, marca/IP, suporte | GitHub/registrar/host, SaferNet se direitos humanos, policia local/federal conforme caso |
| Fraude em compra real | Financeiro, suporte, juridico | Steam/Google/Apple/processador; policia se houver crime |
| Conteudo de abuso sexual infantil | Juridico e seguranca imediatamente | Policia/Comunica PF/Disque 100/SaferNet; canais equivalentes do pais |
| Ameaca, extorsao ou risco a vida | Responsavel legal imediatamente | Policia/emergencia local antes de qualquer outro fluxo |
