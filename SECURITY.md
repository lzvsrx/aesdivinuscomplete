# Politica de seguranca

## Como reportar

Nao abra uma issue publica para vulnerabilidades, dados pessoais expostos, tokens, falhas de autenticacao ou problemas que possam prejudicar usuarios.

Envie um reporte privado para a equipe da LZASANTOSWORLDSGAMES pelo canal oficial definido pela empresa. Enquanto o canal publico definitivo nao existir, use contato direto do mantenedor do repositorio.

Inclua:

- descricao do problema;
- passos para reproduzir;
- impacto possivel;
- arquivos, versoes ou plataformas afetadas;
- evidencias tecnicas sem expor dados pessoais de terceiros.

## Escopo

- jogo web;
- builds Electron para Windows/Linux;
- projetos Android/iOS;
- projeto Godot/C++;
- sistema de save local e sincronizacao GitHub configuravel;
- documentos legais e de conformidade.

## Regras de protecao

- Nunca incluir token GitHub, senha, keystore, certificado Apple/Android ou credenciais no repositorio.
- Dados de usuarios devem ser minimizados, sanitizados e redigidos em sincronizacao remota.
- Incidentes devem seguir `docs/PLANO_RESPOSTA_INCIDENTES_CIBERNETICOS.md`.
- Contatos de autoridades e pontos de referencia ficam em `docs/CONTATOS_AUTORIDADES_CIBERNETICAS_GLOBAIS.md`.

## Nota legal

Qualquer comunicacao com orgaos publicos, autoridades, plataformas ou usuarios deve passar por revisao humana juridica e tecnica antes do envio.
